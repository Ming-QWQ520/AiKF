  AiKF 0.1.0 —— 清除 MP3 残留代码（m3u8 / MP4 双协议）
═══════════════════════════════════════════════════════════

【版本说明】
  版本号 0.1.0（package.json / Cargo.toml / tauri.conf.json /
  关于页 一致）；标题栏不显示版本号，与窗口融为一体。

【本版修复 / 改进】

  1. 全局清除 MP3 / 音频线路的残留代码（应用正式只支持
     m3u8 与 MP4 两类源）：
     · 播放页：删除音频判定与「MP3」协议标签，线路协议
       只显示 m3u8 / MP4 / 未知；缩略图预览不再做音频跳过
       判断
     · 缓存页：删除音频源判定、「MP3」紫色协议标签、选源
       策略中的音频回退；已缓存集数的协议角标只区分
       m3u8 / MP4；报错文案同步更新
     · 下载引擎（cache.rs）：删除音频直链判定、音频扩展名
       扫描、旧版 episode.mp3 固定文件名兜底（通用
       episode.* 文件兜底仍在，旧直链缓存播放不受影响）；
       直链下载的索引类型统一记为 mp4
     · 本版 Rust 侧有改动（仅 cache.rs 内部清理，命令接口
       与参数不变），需完整重新编译

  2. 上一版保留：下载页 Steam 风格改版（指标条 / 分区
     标题 / 绿色进度条 / 估计剩余时间 / 清除全部二次确认）、
     底栏移除「下一集」并放大「设置」「小窗播放」按键。

【上一版保留的能力】
  · 并发下载全协议生效（并发集数池）、弹层统一遮罩、
    启动死锁修复、无资源角标 + 返回键、MP4/m3u8 双协议
    贯通、全局下载坞、缓存弹幕、原生小窗、播放锁定
    （鼠标可见）、播放中测速不切线等

【使用提示】
  · 解压后请完整覆盖工作目录再 pnpm i（依赖无变化可跳过），
    然后 pnpm tauri dev / pnpm tauri build
  · dist/ 为已构建好的前端产物，tauri build 会自动重新生成
  · 本版 Rust 侧仅 cache.rs 内部清理（删音频分支与旧兜底），
    命令签名不变；前端已经 vue-tsc 类型检查 + 无头浏览器
    30+26+17 项断言全部通过
